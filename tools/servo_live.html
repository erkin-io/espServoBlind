Device

"Set ... position here": switch the motor off, move the cover by hand, then press. "Go" is a normal move, as from Zigbee. The Zigbee network key is never shown.

Settings

The same settings as in Zigbee2MQTT, saved in the device. "Save" does not move the servo: the next move uses the new value. "Copy value from slider" puts the pulse of the slider above into the box, so you can find a position with Motor ON and then save it. Pulses: 500 to 2500. Speed: 0 = the full speed of the servo. Motor-off delay: 0 = hold forever, else 500 or more.

Backup

The file holds the four settings above, feedback on or off, and the calibration. It holds nothing about the Zigbee network. The import shows the values and asks before it writes them. It does not move the servo. A calibration is correct only for the servo it was made with: for a different servo, clear the box and run Auto calibrate. The import of a calibration needs firmware 1.3.0 or later.

History

Each change of a value in the Device table, newest first. Values that change all the time (voltage, temperature, uptime) are not listed.
